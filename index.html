想把自己常用的线路排到最前：在仓库根目录 pins.txt 里加一行站点名关键词（一行一个，越靠前优先级越高），下一次构建生效。

口径说明

「可播率」= CMS 接口类站点内按层规模还原的分层加权估计，不是「抽样站点中全部成立的比例」，也不是全站可播率；分母口径为：CMS 站点数 / 抽样本数 / 权重覆盖率（见上方卡片与趋势图注），spider/jar 与 drpy 站点不进分母。「误杀率下界」= 被判 fail 的站点抽样后用真实 TVBox UA 复核复活的比例，n 小、Wilson 区间宽，仅作单日参考、不作趋势比较；所有判定都在 GitHub Actions 云端网络执行，本机结果只作调试。 站点排序依据：置顶名单 > 端到端实测可播 > 影视类目 > 探活分层 > 首页等级 > 每屏去同源（见上节）。
本项目仅聚合公开配置文件，不托管任何视频内容。健康页与配置均由 Actions 自动生成。
